# Life, Yousef

A love letter at dawn — a small static website. Scrolling moves the sky from night to sunrise as the letter reveals itself line by line, with *Love Song* by 311 as the soundtrack.

## Files

- `index.html`: the page and the letter text
- `styles.css`: the sky, sunrise, and typography
- `script.js`: scroll-driven dawn, line reveals, music toggle, and sharing

## Music

The page looks for `assets/love-song-311.mp3`. That file is not in the repository; add your own legally obtained copy there. Without it, the page opens the song on Spotify instead.

## Run locally

Open `index.html` in a browser. No build step is needed.

## Publish with GitHub Pages

In the repository, go to **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
